# Material de entrada

- `voz.wav` — narración (opcional). Si existe, `python3 reel/make.py` sincroniza todo con ella palabra a palabra.
- `clips/madrid.mp4`, `clips/candelago.mp4`, `clips/a_barca.mp4` — grabaciones de Google Earth (opcionales).
  Si faltan, se usan las maquetas 3D propias.
- `referencia/` — episodios anteriores (identidad visual).
