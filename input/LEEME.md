# Material de entrada

- `voz.wav` — narración (opcional). Si existe, `python3 reel/make.py` sincroniza todo con ella palabra a palabra.
- `clips/madrid`, `clips/candelago`, `clips/a_barca` — grabaciones de Google Earth (opcionales): `.mp4`, o el `.zip`
  de fotogramas que exporta Google Earth Studio (también vale la carpeta descomprimida).
  Si faltan, se usan las maquetas 3D propias.
- `referencia/` — episodios anteriores (identidad visual).
